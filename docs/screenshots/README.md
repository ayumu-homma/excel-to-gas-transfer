# 説明用の図について

`excel-import-demo.gif` と `excel-import-before-after.png` は、デモ用アカウントでの **実操作画面** です。顧客の本番環境ではありません。プロフィール画像などの個人情報は伏せています。2026-11-11 に、このリポジトリの `src/Code.gs` をそのまま実行し、1回目は追加3・スキップ1・エラー0、2回目は追加0・スキップ4・エラー0になることを確認しています。

それ以外の PNG は、**実際の Google スプレッドシートの画面を撮影したものではありません。** 列構成と処理前後の違いを、説明用に組んだ図です。

- `input-before.png` … 取り込み前の「入力」シート。3行目は1行目と同じキー
- `dest-after.png` … 取り込み後の「取込」シート。重複行は含まれない
- `log-after.png` … 「実行メモ」に追加3・スキップ1と記録された状態

ダミーの商品名だけを使っています。実在の顧客情報はありません。

図の元になる HTML は `docs/screenshots/mocks/` にあります。再生成する場合のコマンド例（リポジトリのルートで）:

```bash
python3 docs/screenshots/render.py
```
