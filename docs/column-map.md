# 列の対応

公開用サンプルの列定義です。実在の取引先名や個人情報は使いません。

## 入力（Excel / CSV / 「入力」シート）

| 列名 | 例 | 必須 |
| --- | --- | --- |
| 日付 | 2026-11-01 | はい（空ならその行はエラー） |
| 商品名（ダミー） | サンプル紅茶（ダミー） | はい |
| 数量 | 3 | いいえ |
| メモ | 初回分 | いいえ |

重複の判定は、**日付の表示文字列** と **商品名（ダミー）** をトリムした組み合わせです。数量やメモが違っても、同じキーなら2回目以降はスキップします。日付はシート上の表示値を使うため、`setupOnce` とサンプルファイルでは `yyyy-mm-dd` で統一しています。

## 取込シート

入力の4列に加え、次の2列を自動で付けます。

| 列名 | 内容 |
| --- | --- |
| 取込日時 | 実行した日時（Asia/Tokyo） |
| 取込元 | `入力シート` |

## 実行メモ

| 列名 | 内容 |
| --- | --- |
| 実行日時 | 実行した日時 |
| 追加 | 新たに書いた行数 |
| スキップ（重複） | 既に同じキーがあった行数 |
| エラー | 列不足や、日付・商品名が空の行など |
| 結果メモ | 短い説明。列名 typo があればここに書きます |
